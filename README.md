# 🎸 The Red Ram — Chord Charts & Setlists

Official live chord chart viewer and interactive song editor for **The Red Ram**.

🌐 **Live Site**: [https://majora1987-debug.github.io/chords/](https://majora1987-debug.github.io/chords/)

---

## ✨ Features

- **📱 Band Viewer Mode (`index.html`)**:
  - Clean two-panel desktop layout and mobile-optimized slide view.
  - Real-time search by song title.
  - Live transposition (`+/-` semitones) with automatic key indicator updates.
  - Stage-ready Dark & Light modes.

- **✏️ Interactive Chord Editor (`editor.html`)**:
  - **Lyrics / Text Mode**: Copy/paste plain lyrics or ChordPro `[Chord]` bracket notations with live two-way sync.
  - **Visual Chord Editor**: Click directly above any word to open the floating chord picker popover.
  - **Dynamic Section Dragging**: Drag section dividers (`⠿`) to any line boundary with live preview.
  - **Smart Key Detection**: Automatically analyzes chord progressions to detect the song's musical key.
  - **Direct GitHub Sync & Offline JSON**: Save updates directly to GitHub via Personal Access Token (PAT) or download song JSON files locally.

---

## 🚀 GitHub Pages Setup

1. Go to **Settings** $\rightarrow$ **Pages** in the GitHub repository.
2. Under **Build and deployment** $\rightarrow$ **Source**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then click **Save**.
4. Your chord charts will be live at `https://majora1987-debug.github.io/chords/`!
